# ADR-0007: 題材の出典を気象庁ホームページ（気象・防災）に選定する

## ステータス

Accepted

## 日付

2026-08-18

## 決定内容

チャットボットの題材を NASA（極限天体）から**気象庁（気象・防災）**へ全面的に乗り換え、出典を気象庁ホームページに一本化する。

- 取り込むのは**過去の記録と解説のみ**とし、予報データは一切取り込まない（気象業務法対応。ADR-0008）
- 利用するページの一覧と再利用根拠は [docs/data-sources.md](../data-sources.md) を正本とする
- 出典表示は気象庁が示す記載例に厳密に従う（ADR-0008）

本プロジェクトの真の成果物は PostgreSQL の Backup / Restore(PITR) / Maintenance / Monitoring であり、チャットボットは題材にすぎない。5 日間の個人開発において、題材側の権利リスク対応・翻訳工程に作業量を割く選択は減点であり、それらが構造的に不要になる出典を選ぶ。

## 背景

NASA を出典として採用していた（ADR-0006）が、権利精査で解消不能な問題が判明した。

### NASA の問題点

1. **著作権フリーの明言が米国内限定。** NASA の方針は "generally are not subject to copyright **in the United States**" であり、日本での扱いに言及がない。CC0 が及ぶのは観測データのみで、解説文には及ばない
2. **AI 製品での帰属表現を明文で禁止。** NASA Brand Center の AI 条項は "References like \"according to NASA\" or similar are **prohibited** in AI products" とする（ADR-0006 はこの条項への準拠設計だった）
3. **英語ソースのため日本語化に翻訳・翻案が必要**となり、権利上さらに踏み込む。実際に要約工程で誤り（数値の誇張）が混入した（Issue #37 / PR #38 で修正）

### 検討した選択肢（各機関の規約）

1. **NASA** — 上記のとおり不採用
2. **JAXA** — サイト利用規約が「事前の許可なく…複製、**改変**…はお断りします」と改変を禁止しており、チャンク分割・RAG 利用に必要な加工ができない。不採用
3. **NAOJ（国立天文台）** — 規約は良好だが、本企画で必要とする体系的な解説コンテンツが不在。不採用
4. **天文学辞典（日本天文学会）** — 要約利用が「要相談」であり、事前相談なしに利用できない。不採用
5. **気象庁**（採択） — 下記のとおり、上記の問題がすべて解決する

### 気象庁の規約（採択理由の根拠）

気象庁ホームページのコンテンツは「公共データ利用規約（第1.0版）」（デジタル庁）準拠で利用できる。気象庁「気象庁ホームページについて」（<https://www.jma.go.jp/jma/kishou/info/coment.html>）より:

> 気象庁ホームページで公開している情報（以下「コンテンツ」といいます。）は、権利表記の記載がない限り「公共データ利用規約（第1.0版）」に準拠した利用条件の下で、利用することができます。

公共データ利用規約（第1.0版）（<https://www.digital.go.jp/resources/open_data/public_data_license_v1.0>）より（2026-08-18 取得）:

> 複製、公衆送信、翻訳・変形等の翻案等、自由に利用できます（…）。商用利用も可能です。
>
> 本利用ルールは、クリエイティブ・コモンズ・ライセンスの表示4.0　国際ライセンスに規定される著作権利用許諾条件（以下「CC BY」といいます。）と互換性があります。

- **翻案（チャンク分割等の加工）が明文で許可**されている。事前申請は不要
- **AI 利用への制約条項はない**（規約本文・解説 PDF・気象庁ページの全文走査でゼロ件を確認済み）
- **日本語ソースなので翻訳・要約の工程自体が不要**。NASA で誤り混入の原因となった英語→日本語要約の工程を消せる

## 採択理由

- 権利面: 翻案許可・商用可・CC BY 4.0 互換・事前申請不要と、必要な利用形態がすべて規約の明文で担保される
- 品質面: 逐語で格納できるため、要約による誤り混入経路（Issue #37）が構造的に消える
- 題材面: 気象庁自身が書いている比喩・体感表現（「バケツをひっくり返したように降る」「沖合いではジェット機に匹敵する速さ」「立っていることができず、はわないと動くことができない」等）が豊富で、一般向けチャットボットの題材として成立する
- 作業量面: 翻訳・権利対応の工数が消え、本来の成果物（PostgreSQL 運用設計）に時間を使える

ただし気象庁固有の制約として、**気象業務法（第17条第1項: 予報業務の許可 / 第23条: 警報の制限）**への対応が必須になる。この設計対応は ADR-0008 に記録する。

## 影響

- `backend/app/ingest/` のシードデータを気象庁出典へ置き換える。旧題材（NASA）のデータは投入経路の差分同期で既存 DB からも撤去する
- `documents` のチャンクは気象庁ページの記述を**逐語**で格納する。行うのはチャンク分割のみで、これが規約上の「編集・加工」に当たるため加工表記を行う（ADR-0008）
- 予報データは取り込まない。過去の記録（歴代ランキング・台風統計）と解説のみ
- DB スキーマ（ADR-0003）は題材非依存設計のため変更しない。`objects` が「台風」「津波」「震度6強」等になる
- 出典の一覧管理は `docs/data-sources.md` を正本とし、ページを追加する際は URL / タイトル / 取得日 / 再利用根拠を記録する
